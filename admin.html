명단 시트 업로드

이름, 이메일 두 열이 있는 시트를 올리면 참여자 명단(인증 화면 드롭다운에 표시)과 알림 메일 수신자 목록([알림 메일] 탭)에 한 번에 등록됩니다. 이미 등록된 이름·메일 주소는 건너뜁니다. 엑셀 파일(.xlsx, .xls)을 그대로 올리거나, 구글 시트에서 "쉼표로 구분된 값(.csv)"으로 다운로드해서 올려도 됩니다.

첫 줄이 "이름, 이메일" 같은 제목 줄이어도 자동으로 건너뜁니다.

제출 기록

날짜 또는 참가자로 필터링해 인증 내용을 확인합니다.

알림 메일

자동 발송 없이 운영진이 직접 보냅니다. 아래에서 받는 사람을 관리하고, 이름을 검색하거나 미인증 경고 목록에서 골라 제목·본문을 자동으로 채운 뒤 [Gmail로 작성하기]로 받는 사람·제목·본문이 채워진 Gmail 새 창을 열어 거기서 보내거나, 복사해서 본인 메일 앱으로 직접 붙여넣어 보내주세요.

한 줄에 "이름, 메일 주소" 형식으로 하나씩 붙여넣으면 여러 명을 한 번에 등록할 수 있습니다. 엑셀에서 이름·메일 두 열을 복사해 그대로 붙여넣어도 됩니다.

등록된 메일 주소

특정 대상에게 안내 메일 작성

위 목록에 등록된 사람을 이름으로 검색해서 고르면, 제목·본문을 채워 드립니다. 자유롭게 고쳐 쓰고 [Gmail로 작성하기]를 누르면 받는 사람·제목·본문이 채워진 Gmail 새 창이 바로 열립니다 (거기서 [보내기]만 누르면 끝). 다른 메일 앱을 쓰신다면 [복사하기]로 담아 붙여넣어 보내셔도 됩니다. 동명이인이 있으면 검색 결과에 모두 나타나니 메일 주소를 보고 정확한 대상을 선택해 주세요.

받는 사람:

Gmail로 작성하기를 누르면 받는 사람·제목·본문이 채워진 Gmail 새 창이 열립니다 — 내용을 확인하고 거기서 [보내기]만 누르면 됩니다.

미인증 경고 메일

현재 미인증 횟수가 있는 참여자 목록입니다(이미 아웃 처리된 분은 빠집니다). [메일 작성]을 누르면 지금까지 몇 회 미인증됐는지와 누적 회가 되면 킥아웃될 수 있다는 내용을 자동으로 채운 제목·본문이 위 작성창에 채워집니다 — 확인 후 [Gmail로 작성하기]나 [복사하기]로 보내주세요.

킥아웃 통보 메일

[명단 관리]에서 킥아웃 처리된 참여자 목록입니다. [메일 작성]을 누르면 더 이상 이번 챌린지에 참여할 수 없다는 안내와 다음 챌린지 재신청 안내를 담은 제목·본문이 위 작성창에 채워집니다 — 확인 후 [Gmail로 작성하기]나 [복사하기]로 보내주세요.

킥아웃 통보 메일 문구 편집

위 [메일 작성]을 눌렀을 때 채워지는 기본 제목·본문을 직접 고쳐서 저장해 둘 수 있습니다. {{이름}}은 그 참여자 이름으로, {{킥아웃기준}}은 js/config.js의 킥아웃 기준 횟수로 자동 치환됩니다. 저장하면 그 다음부터 계속 이 문구가 쓰이고, [기본값으로 되돌리기]를 누르면 원래 문구로 돌아갑니다.

데이터 관리

현재 저장 위치: Firebase Firestore — 참가자들이 각자 어떤 기기·브라우저에서 제출하든 하나의 데이터베이스에 함께 저장·집계됩니다.

백업 복원

내려받은 JSON 파일을 불러오면 현재 데이터를 덮어씁니다.

Firebase 연결

나중에 여러 기기에서 함께 쓰려면 js/config.js의 CS.FIREBASE_CONFIG를 채우고 backend를 'firebase'로 바꾸면 됩니다. 저장 인터페이스가 동일해 화면 코드는 그대로 동작합니다. 전환 전에 위의 전체 백업을 받아두고, 전환 후 복원하기로 그대로 옮길 수 있습니다.
