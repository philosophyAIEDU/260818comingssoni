# 『꿈과 돈』 정리본 — 커밍쏜이 직접 고친 것에서 배운 것 (2026-10-21)

- 초안(Claude가 올린 판): `references/s2-꿈과돈-초안.md`
- 최종(커밍쏜이 고쳐서 게시한 판): `archive/s2-꿈과돈/인사이트정리본.md`
- 그대로 둔 것: 3줄 요약, 목차, 꼭지 제목 5개, 들어가며, 인용한 책 문장, 꼭지 순서. → **설계(5꼭지·왜→무엇→어떻게)는 통과**했다.
- 고친 것은 전부 **본문 안**이었다. 크게 두 갈래로 나뉜다. ① 맥락이 모자라서 읽는 사람이 한 번 더 생각해야 했던 곳에 설명을 보탰다. ② 꼭지 주제와 결이 다른 내용을 덜어 냈다.

## ② 꼭지와 결이 다른 내용은 덜어 낸다 (가장 큰 수정)

| 꼭지 (주장) | 뺀 것 | 왜 안 맞았나 |
| --- | --- | --- |
| 3. 실력의 늪에서 나오세요 | 에어비앤비 프라이팬 일화, "불편한 게 있으나 마음을 훔치는 서비스" 인용, "6개월 준비하지 말고 최소 만족선으로 열어라" 단락, 실행 "요청 하나를 다음 날 안에 해결" | 주장은 '실력만 쌓지 말고 팔아라'다. 프라이팬은 '부족함을 채워 감동을 주는 서비스' 이야기라 다른 꼭지 감이다. 좋은 일화여도 끼워 넣지 않는다. |
| 3. 〃 | 실행 1의 "럭셔리부터 만들까 프리미엄부터 만들까는 순서가 바뀐 질문" | 상품 분류는 5꼭지 주제다. |
| 5. 상품은 두 칸으로, 콘텐츠는 여정으로 | 커뮤니티 단락 전체(저/중/고관여, "커뮤니케이션이 없으면…" 인용, 인사이트 파티 스태프), 실행 3 "커뮤니티 관여도 3단계" | 주장은 상품 분류와 콘텐츠→돈 설계다. 커뮤니티는 다른 주제다. |
| 5. 〃 | "상세 페이지는 설득이 아니라 검증의 영역", "어그로 콘텐츠만 만들면…" | '콘텐츠가 고객을 거른다'는 한 문장이면 충분했다. 덧붙인 개념이 흐름을 끊었다. |
| 4. 꿈을 숨기지 마세요 | "꿈은 내가 좋았던 것들의 총합이에요" | 바로 뒤 '과거의 나를 왜 돕고 싶은가'와 결이 다른 정의를 하나 더 얹은 꼴이었다. |

교훈:
- 라이브에서 좋았던 이야기가 꼭지보다 많아도 **전부 담으려고 하지 않는다.** 꼭지 제목의 주장을 돕지 않는 문단은 다른 꼭지로 옮기거나 버린다.
- **실행법 3개를 채우려고 억지로 만들지 않는다.** 3·5꼭지는 2개로 줄었고, 그게 더 나았다.
- 남는 문제도 하나 있다. 3꼭지 제목의 "완벽 대신 완료로"는 본문에서 완료주의 단락이 빠진 뒤에도 남아 있다. 본문을 덜어 내면 **제목·목차·3줄 요약도 같이 다시 맞춘다.**

## 그 밖의 결

- 핵심 원리를 **멤버 발언으로 돌리지 않는다.** "한 멤버분이 채팅으로 정답을 주셨죠"를 "쉽게 말씀드릴게요"로 바꿨다. 정리본의 원리는 커밍쏜의 목소리로 말한다.
- 과거의 나는 **단정하지 않고 사실 범위 안에서** 쓴다. "과거의 저는 기능을 팔았어요"를 "과거의 저 역시도 기능을 파는데 집중했던 적이 있었어요"로 바꿨다.
- 독자의 속마음을 대신 물어 준다. "쪽팔린다고요? 짜친다고요?" 같은 반문을 넣었다.
- 실행법은 **기계적 지시보다 스스로 묻게** 한다. "한 줄만 붙이세요"는 "나는 이 콘텐츠에서 … 어떤 라이프스타일을 제안하는가? 다시한번 생각해보세요"로 바꿨다. 대본에 없는 구체적 위치 지시("채널 소개와 고정 댓글에 올리세요")는 "정리해보세요"로 걷어 냈다.
- 👉 내게 적용은 행동에 **태도까지** 붙인다. "한 번 더 말한다"는 "한 번 더 말하고 알린다"로, "두 문장으로 넣는다"는 "최소 두문장을 넣으며 당당하게 드러내본다"로 바꿨다.
- 굵게는 핵심 문장을 꼭지당 1~3개 썼다(구조용 '이렇게 적용해 보세요'·'👉' 제외). 2꼭지는 3개였다. 단어 몇 개가 아니라 단락의 결론 문장을 통째로 굵게 했다.
- 마무리는 **공동체를 이름으로 부르고 함께 가자고** 끝낸다. "같은 결의 사람들 곁에 와 있어요"는 "지금 퍼메스 독서멤버십에서는 브랜딩을 통해 삶의 주인공이 되어가고 싶은 여러분과 같은 결의 사람들이 모여있어요… 저 역시도 계속해서 제 노하우와 경험을 아낌없이 공유할게요. / 계속해서 같이가보시죠."로 바꿨고, 그다음에 서명이 온다.
