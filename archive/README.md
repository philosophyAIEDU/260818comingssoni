# 시즌별 보관함 — 이전 버전 문구를 지우지 않는다

시즌이 바뀌어도 지난 시즌의 상세페이지·설명서·일정표·카톡 공지 문구는 **지우지 않고 여기 보관**한다.
이미 게시한 문구를 고칠 때도 고치기 전 문구를 `변경기록.md`에 남긴다.

| 폴더 | 시즌 | 기간 |
| --- | --- | --- |
| `s1-프로세스이코노미/` | 8월 『프로세스 이코노미』 | 2026-08-24 ~ 09-20 |
| `s2-꿈과돈/` | 9월 『꿈과 돈』 | 2026-09-21 ~ 10-18 |
| `s3-혁명의팡파르/` | 10월 『혁명의 팡파르』 | 2026-10-21 ~ 11-17 |

## 무엇이 어디에 남아 있나

- **앱 문구(책 소개·규칙·일정·발제문)** — `js/config.js`의 `CS.SEASONS`에 시즌마다 그대로 남는다.
  새 시즌은 새 id(s4, s5 …)로 **덧붙이기만** 하고 지난 시즌 객체는 지우지 않는다(지난 시즌은 `lockAt`으로 닫힐 뿐).
- **노션 페이지** — 시즌마다 새 페이지를 만들고 지난달 페이지는 그대로 둔다(새 페이지를 지난달 페이지의 하위로 만든다).
- **노션 페이지 사본(이 폴더)** — 게시한 페이지를 마크다운으로 떠 둔 것. 노션이 바뀌거나 지워져도 문구가 남는다.
  ```
  node tools/notion-snapshot.mjs <노션 페이지 ID> archive/<시즌id>-<책>/상세페이지.md
  ```
  같은 이름의 파일이 이미 있으면 덮어쓰지 않고 `상세페이지.2026-10-13_2306.md`처럼 날짜를 붙여 따로 남긴다.
- **도구가 만든 초안** — `out/<시즌id>/`(커밋하지 않는 작업 폴더). 시즌마다 폴더가 달라 앞 시즌 초안을 덮어쓰지 않는다.

## 이미 게시한 문구를 고칠 때

1. 고치기 전에 `node tools/notion-snapshot.mjs …`로 지금 판을 떠 둔다(날짜 붙은 파일로 남는다).
2. 노션에서 고친다.
3. 그 시즌 폴더의 `변경기록.md`에 날짜 · 무엇을 · 왜 · 고치기 전/후 문구를 적는다.
4. 고친 판도 다시 떠 둔다.

신청자 명단(이름·이메일·전화번호)과 라이브 대본은 여기에 두지 않는다(개인정보 — 저장소에 올리지 않는다).
